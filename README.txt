# AutoCom

Веб-приложение для автоматизации работы автосервиса.

## Технологии

- C#
- ASP.NET Core Razor Pages (.NET 9)
- Entity Framework Core 9
- PostgreSQL
- Bootstrap

## Основные возможности

- Регистрация и авторизация пользователей
- Личный кабинет клиента
- Управление автомобилями клиентов
- Администрирование услуг и механиков
- Учёт запчастей и складских остатков
- Работа с заказ-нарядами

## Структура проекта

- `AutoComWeb/Pages` — страницы и обработчики запросов
- `AutoComWeb/Models` — модели предметной области
- `AutoComWeb/Data` — контекст и миграции Entity Framework Core
- `AutoComWeb/Services` — сервисный слой
- `AutoComWeb/wwwroot` — CSS, JavaScript и статические файлы

## Запуск

1. Установить .NET 9 SDK и PostgreSQL.
2. Создать локальную базу данных `AutoComDB`.
3. Настроить строку подключения через .NET User Secrets или переменные окружения.
4. Восстановить зависимости командой `dotnet restore`.
5. Запустить приложение командой `dotnet run --project AutoComWeb/AutoComWeb.csproj`.

> Схема базы данных и миграции должны соответствовать текущей конфигурации проекта. Перед запуском на другом компьютере проверьте способ создания и обновления схемы PostgreSQL.
